# Traffic Control System 🚦

A microcontroller-based **Traffic Control System** designed to manage and simulate traffic signals using embedded systems concepts.

## 📌 Project Overview

The Traffic Control System is an embedded-system project that demonstrates how traffic signals can be controlled automatically using a microcontroller. The project focuses on controlling traffic lights according to predefined timing sequences and can be tested through **Proteus simulation**.

This project provides a practical implementation of digital logic, microcontroller programming, and traffic signal control.

## 🎯 Objectives

* Design an automated traffic signal control system.
* Control traffic lights using a microcontroller.
* Implement predefined timing sequences for traffic signals.
* Simulate and test the system in Proteus.
* Demonstrate practical applications of embedded systems.

## ⚙️ How It Works

The system controls traffic lights through a programmed microcontroller. Each traffic direction follows a predefined sequence:

```text
RED → GREEN → YELLOW → RED
```

The microcontroller sends appropriate control signals to the traffic lights, allowing traffic to move safely and systematically.

The circuit can be simulated in **Proteus** before being implemented on physical hardware.

## 🧪 Simulation

The Proteus project allows the traffic control logic to be tested virtually.

### Basic Simulation Process

1. Open the Proteus project.
2. Load the provided microcontroller program.
3. Compile/build the source code if required.
4. Load the generated program file into the microcontroller.
5. Run the simulation.
6. Observe the traffic signal sequence.
